# Isekai Hero for Skyrim Special Edition

[![Skyrim SE](https://img.shields.io/badge/Skyrim%20SE-Compatible-brightgreen)]()
[![ESL](https://img.shields.io/badge/ESL%20Flag-Compatible-blue)]()

Start your Skyrim adventure as an overpowered hero! Inspired by Isekai anime, this mod lets you choose your power level after character creation.

## Features

- **Three Power Levels**: Normal, Hero, or God Mode
- **Skill Distribution**: All skills, Warrior, Mage, Thief, or Custom
- **Equipment Choices**: From humble gear to legendary items
- **Immersive Intro**: Dialog-driven awakening sequence
- **MCM Support**: Respec and configure later (optional)
- **ESL Flagged**: Saves plugin slot

## Requirements

- Skyrim Special Edition (1.5.x or 1.6.x)
- [Optional] SkyUI for MCM menu

## Installation

### Manual
1. Download and extract
2. Copy `IsekaiHero.esp` and `Scripts/` folder to your Data directory
3. Enable in your mod manager

### Mod Manager
1. Install with Vortex/Mod Organizer 2
2. Enable plugin

## Usage

1. Create your character as normal
2. After spawning in the world, the Isekai Awakening will trigger
3. Choose your power level through the dialog
4. Select your skill focus
5. Choose your starting equipment
6. Begin your adventure!

### Power Levels

| Level | Description |
|-------|-------------|
| **Normal** | Vanilla Skyrim experience |
| **Hero** | Max skills (100), Level 1 |
| **God Mode** | Max skills, Level 81, 80 perk points |

### Skill Focus

- **All Equal** - 100 in every skill
- **Warrior** - Combat skills focused
- **Mage** - Magic skills focused
- **Thief** - Stealth skills focused
- **Custom** - Configure via MCM later

## Compatibility

- ✅ Alternate Start - Live Another Life
- ✅ Vanilla start
- ✅ ESL flagged (doesn't count towards 255 plugin limit)
- ✅ Minimal script load (no OnUpdate loops)
